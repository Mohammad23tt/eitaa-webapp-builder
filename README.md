# Eitaa WebApp Builder Skill

**اسکیل حرفه‌ای و جامع برای ساخت برنامک (Web App / Mini App) پیام‌رسان ایتا**

این ریپوزیتوری یک **Skill** آماده برای استفاده در محیط‌های مبتنی بر Grok / Agent Skills است و همچنین به عنوان راهنمای مرجع برای جامعه توسعه‌دهندگان ایرانی منتشر شده است.

## این اسکیل چه کاری انجام می‌دهد؟

- راهنمای گام‌به‌گام ثبت برنامه در [ایتایار](https://eitaayar.ir)
- اتصال صحیح و امن به SDK رسمی ایتا (`eitaa-web-app.js`)
- استفاده از متدهای کلیدی (MainButton، showPopup، requestContact، HapticFeedback و ...)
- بهترین شیوه‌های امنیتی (اعتبارسنجی `initData` سمت سرور)
- پشتیبانی کامل از RTL و فونت فارسی
- قالب آماده برای شروع سریع
- نکات دیباگ روی اندروید و دسکتاپ
- الگوهای ساخت بازی و اپلیکیشن تعاملی داخل ایتا

## ساختار فایل‌ها

```
eitaa-webapp-builder/
├── SKILL.md                          # فایل اصلی اسکیل (برای Agent)
├── README.md                         # این فایل
└── references/
    ├── sdk-methods.md                # مرجع سریع متدها و اشیاء SDK
    └── quick-start-template.md       # قالب HTML + JS آماده اجرا
```

## نحوه استفاده به عنوان Skill

اگر از محیط‌هایی مثل Grok با پشتیبانی از Agent Skills استفاده می‌کنید، کافی است این ریپو را کلون کرده یا محتوای `SKILL.md` را در پوشه skills خود قرار دهید. تریگرهای اصلی شامل کلماتی مثل «ایتا»، «برنامک ایتا»، «eitaa webapp»، «ساخت بازی ایتا» و ... هستند.

## نحوه استفاده به عنوان مستند

حتی اگر از Skill استفاده نمی‌کنید، فایل‌های داخل `references/` و `SKILL.md` یک راهنمای عملی و به‌روز برای ساخت برنامک ایتا هستند.
